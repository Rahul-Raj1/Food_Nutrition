NutriClass – Food Classification Using Machine Learning
📌 Project Overview

NutriClass is a machine learning-based food classification system that categorizes food items into seven classes—Banana, Burger, Donut, Ice Cream, Pasta, Pizza, and Sushi—based on their nutritional attributes. The project demonstrates how data-driven approaches can be used to analyze nutritional information and automatically classify food items with high accuracy.

🎯 Objectives

Perform Exploratory Data Analysis (EDA) on nutritional data

Clean and preprocess the dataset (null removal, duplicate removal, outlier treatment)

Scale numerical features and encode categorical variables

Train multiple machine learning classification models

Compare model performance using evaluation metrics

🛠️ Tools & Technologies Used

Jupyter Notebook

Pandas & NumPy – Data manipulation

Matplotlib & Seaborn – Data visualization

Scikit-learn – ML model implementation

XGBoost – Advanced boosting model

📊 Data Preprocessing

Removed missing and duplicate values

Treated outliers using IQR method

Applied feature scaling (Standardization)

Encoded categorical variables

Performed train-test split

🤖 Machine Learning Models Implemented

Logistic Regression

Decision Tree

Random Forest

K-Nearest Neighbors (KNN)

Support Vector Machine (SVM)

Gradient Boosting

XGBoost

All models achieved approximately 90%+ accuracy, with XGBoost showing the best overall performance.

📈 Evaluation Metrics

Accuracy

Precision

Recall

F1-Score

Confusion Matrix

🚀 Future Scope

Expand dataset with more food categories

✅ Conclusion

NutriClass successfully demonstrates the effectiveness of machine learning in nutritional food classification. The comparative analysis of seven models highlights the strength of ensemble methods, particularly XGBoost, in handling structured nutritional data efficiently.
